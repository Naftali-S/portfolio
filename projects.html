Internship Scraper

Personal project · 2026 – Present

A Python tool that checks 52 companies across 11 job-board platforms every day and emails me only the new internship postings in Ottawa, Kanata and remote-Canada.

What I did

  • Reverse-engineered each platform's JSON API using browser dev tools, so no browser automation or HTML scraping is needed.
  • Stored results in a SQLite database committed to the repo, so each run knows what's already been seen.
  • Automated it with GitHub Actions to run daily and send a digest email.
  • Python
  • GitHub Actions
  • SQLite
