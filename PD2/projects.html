Yatzy

CST3106 · Assignments 1 and 2 · Fall 2026

A single-player Yatzy game, built first as a browser-only app and then rebuilt so a Node.js and Express server runs the game.

What I did

  • Split the game into Dice, YatzyEngine and YatzyGame classes, with 100 automated tests.
  • Built a REST API in Express that rolls the dice, scores every box and stores each game on the server.
  • Connected the page to the API with the Fetch API and async/await.
  • JavaScript
  • Node.js
  • Express

Internship Scraper

Personal project · 2026 – Present

A Python tool that checks 52 companies across 11 job-board platforms every day and emails me only the new internship postings in Ottawa, Kanata and remote-Canada.

What I did

  • Reverse-engineered each platform's JSON API using browser dev tools, so no browser automation or HTML scraping is needed.
  • Stored results in a SQLite database committed to the repo, so each run knows what's already been seen.
  • Automated it with GitHub Actions to run daily and send a digest email.
  • Python
  • GitHub Actions
  • SQLite
